# Backspin Records

## About the Project

Backspin Records is a vinyl marketplace project for CIS2232 and CIS2250. Collectors and artists can list new or used vinyl records for sale.

Record information includes the record name, seller and customer names, release year, genre, colour, size, and whether the vinyl is sealed.

## Current Stage

The project begins as a basic Java console application with order information stored in a JSON file. Price calculations will be added later.
